# Kmojis: Emojis for Knowledge work

An emoji guide for your knowledge work.

🔮 = insight  
🔑 = answer (in issue/thesis tree)  
❓ = question  
💡 = idea  
🕳️ = blackhole / distraction  
➰ = aside (or distraction)  
🗞️ / 👣 = papertrail  
🐦 = posted online somewhere e.g. as post, tweet etc  

### Tasks

Task status

✅ = complete/closed  
❌ = wontfix in task process  
⛔ = blocked in task process  
💤 = backburner / someday in task process  

Task priority

⏫ = v high priority  
⏭️ = next (in GTD sense)  

Task type / size

🐳 = large  
🎧 = deep work (also tag `deepwork`)  
🪫 = low energy  
🔧 = chore  

Time estimation

⏲️ = estimated time  
⌛ = actual time taken  

e.g.

```
⏲️10m
⌛1h
```

### Phase

📥 = Inbox  
📋 (clipboard) = project/task  
🧩 (jigsaw) = shaping  
🖍️ = shaping  

## Inbox (in consideration)

🧐 = needs further investigation e.g. if something in a book or my own work where needs checking or exploring further.  
❗ = in a book, something that is dubious. in task planning a problem or issue  
🚩 = a red flag or significant issue (that will need to be raised with others).
